# 本轮交付与能力边界（2026-09-10）

定位：本地语音风险证据与分角色确认原型。仍不具备生产 SDK、多租户、真人身份登记或真实银行工具执行能力。

## 已完成

| 能力 | 当前可运行内容 |
|---|---|
| 语音流程 | AssemblyAI → 转录修订 → 英文规则 → 风险状态 → 提醒；同一流程支持文本备用 |
| 生命周期 | 撤回/重置由服务端取消任务；会话代次拒绝旧回调；并发语音拒绝；60 秒前端录音和 90 秒后端流上限 |
| 分角色确认 | 不同入口凭据、请求范围和有效期、六位挑战、三次错误取消、签名及一次性模拟执行 |
| 图论 | 复用 NetworkX；当前会话的转录版本→风险事件→类别来源图；重复类别不重复计分 |
| 密码学 | 复用 cryptography Ed25519 和 SHA-256；可下载当前风险回执，使用预留公钥和会话 ID 离线验签 |
| 测量 | 完成/故障/取消/断开分开统计；有效提醒代理值 P50/P95；有界内容最小化 JSON 导出 |
| 自动化验证 | Python 协议、取消、跨会话、权限、篡改测试；Node 浏览器逻辑测试；不需付费 API |

请求端和审核端是分离角色，不证明由两个不同真人操作。参与者一旦同时得到审核入口和挑战码，仍可自批；挑战码不替代身份登记或已登记联系方式。

本轮本地验证：160 项 Python 测试通过、0 跳过；3 项 Node 前端逻辑测试通过；25 条内部合成用例状态/事件回归通过。机器报告见 [local-check.json](../scambench/local-check.json)。未调用付费 ASR；未完成本轮真实麦克风复测；GitHub Actions 仅更新配置，尚未确认远程执行结果。

## API 与报告契约

这些是本地实验接口，兼容性范围限于本仓库，全部要求 Participant bearer 凭据及现有 Host/Origin 检查：

| 接口 | 版本/用途 |
|---|---|
| GET /api/evidence | callgate-evidence-v1：来源图、权重贡献、非概率分数和不确定性 |
| GET /api/metrics/export | callgate-live-metrics-v2：最近 100 次流的数值、结果和定义；报告丢弃数量 |
| GET /api/receipt-key | 本次启动的 Ed25519 公钥；应提前独立保留 |
| POST /api/receipt | callgate-receipt-export-v1：已同意且有证据的当前风险快照 |

回执不包含转录，但包含会话标识和元数据摘要；不是匿名数据或真实支付回执。回执签名只验证字节和签名密钥，不验证风险判断正确。下载行为由用户触发，下载后的文件不会随服务退出删除。

故障比例 = failed / (completed + failed)。取消和原因不明的断开单列，均不伪装为成功。未通过身份/同意/密钥配置检查的连接未进入测量分母。延迟只汇总完成的流中首次新触发的最终风险提醒；同一会话再次听到相同风险可能没有新提醒。客户端显示/音频设备延迟尚未测量，不可声称完整端到端 SLA。

## 数学与开源组件的实际使用

- NetworkX 与 cryptography 已真实接入，不需要复制上游算法或自行实现椭圆曲线。
- 规则分数为 min(100, Σ distinct category weights)，不是 P(诈骗|证据)；证据图是来源图，不是因果图或图神经网络。
- Wilson 区间和混淆矩阵已用于内部合成回归集。25 条同作者样例仍不能作为真实泛化准确率。
- [pgmpy](https://pgmpy.org/) 可实现概率图推断；本项目没有适合估计先验/条件概率的独立数据，尚未训练或接入概率风险模型。
- [River](https://riverml.xyz/) 的流式学习/漂移实验需要冻结基线和可靠标签。目前没有新增该依赖，不能声称在线学习。

## ZK：已评估，尚未实现

[Semaphore V4 官方文档](https://docs.semaphore.pse.dev/) 的目标是匿名群组成员发出消息并防重复表达。它适合未来“证明确认者属于已登记的合格群组，但隐藏具体成员”的需求；不判断诈骗，也不建立真实身份。

接入所需验收条件：可信成员登记；可信且可撤销的群组根；proof message 绑定版本、会话、操作摘要和批准位；scope 绑定确认请求；nullifier 原子防重放；拒绝伪造/过期群组根、错误消息、跨请求证明；固定并验证上游证明产物；实测证明耗时。

当前缺少登记、根治理和实际证明生成/验证，故未添加伪 ZK 接口、未用哈希冒充 ZK。Circom、GNN、tokenomics 同样没有集成；当前没有数据或产品场景足以验证其价值。
